    这不是官方地图，也不是实时数据

    本页把公开比赛数据中的首圈中心、决赛圈、红区落点聚合到 0—1000 的坐标空间，用日志强度的热区显示集中程度。底图为原创示意地图，只保留坐标、网格与分区，不使用 PUBG 官方地图、Logo 或音乐。

    数据来源

    • Kaggle: PUBG Match Deaths and Statistics（页面标注 CC0）
    • 聚合 SQL 快照：zcyoop/pubg_data_analysis（仅使用数值聚合）
    • 参考仓库：KaiserW/pubg-data

    限制

    • 圈层/红区来自聚合 SQL 快照；死亡热区来自 6500 万条死亡明细的 100×100 网格聚合。
    • 2018 年数据，不代表当前版本；样本存在低分段种子偏差。
    • 聚合单元与“人数/场次”的确切口径未完全可核验，页面只标为“权重”，不把它解释为绝对玩家数。
    • 热区显示相关性，不构成因果结论；不能替代比赛复盘。
    • 仓库无 LICENSE；本项目为本地研究/教学原型，公开发布或商用前需解决授权与商标问题。
